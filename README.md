# 微博 / X 原生定时助手

一次导入多条文案，生成同步时间表，自动填写并保存平台原生定时文字帖。保存后统一检查待发布列表，确认完成即可关闭电脑。不需要付费 API。

## Chrome 扩展 · v0.1.9

[下载安装包](downloads/social-native-scheduler-chrome-v0.1.9.zip) · [安装和使用说明](extension/README.md) · [更新记录](CHANGELOG.md) · [验证范围](extension/VERIFICATION.md) · [隐私政策](PRIVACY.md)

连续按两次回车分隔文案，设置开始时间和间隔，选择已登录账号，点击“一次性导入全部到平台”。一个平台报错时，另一个平台继续。明确的额度或权限限制会跳过本批剩余的该平台任务，也可手动跳过当前条目。结果不明的保留待核对，已提交的条目不会直接重发。

v0.1.8 已在微博、X 各验证一条多行正文的原生定时保存，并重新读取平台列表确认正文和时间。v0.1.9 的跳过、平台独立继续和额度提示处理通过回归测试及模拟扩展页面测试；尚未在真实账号上重现额度耗尽。详见验证记录。目前供本地加载使用，未上架 Chrome Web Store。

## Codex skill

根目录 SKILL.md 提供原生定时操作流程，references/ 包含网页操作经验，scripts/plan.mjs 可独立生成时间表。skill 与 Chrome 扩展可分别使用。

仓库只包含通用代码和说明，不包含账号信息、浏览器凭据或个人发布记录。
