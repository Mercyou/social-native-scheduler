# 微博 / X 原生定时助手

把帖子存到平台的原生定时列表，保存并核对完成后可以关闭电脑。复用已登录的浏览器，不需要付费 API。

- **Chrome 扩展**：见 [安装和使用说明](extension/README.md)。无需 Codex 或 OpenCLI，支持时间表、编辑器填写和逐条提交；初版需要人工核对平台结果。
- **Codex skill**：根目录 `SKILL.md`，附网页操作经验与时间表工具。

目前 Chrome 扩展交付为可加载的源码，尚未上架 Chrome Web Store；扩展端到端真实账号发布尚未验证。平台控件和会员额度可能变化，遇到不匹配会停止。

仅上传通用源码，没有账号信息、浏览器凭据或个人发布记录。
