# 微博 / X 原生定时助手

一次导入多条文案，生成同步时间表，自动填写并保存平台原生定时文字帖。保存后统一检查待发布列表，确认完成即可关闭电脑。不需要付费 API。

## Chrome 扩展 · v0.1.8

[下载安装包](downloads/social-native-scheduler-chrome-v0.1.8.zip) · [安装和使用说明](extension/README.md) · [验证范围](extension/VERIFICATION.md) · [隐私政策](PRIVACY.md)

连续按两次回车分隔文案，设置开始时间和间隔，选择已登录账号，点击“一次性导入全部到平台”。遇到结果不明时停止，已提交的条目不会直接重发。导入完成后统一检查平台结果。

已在微博、X 各验证一条多行正文的原生定时保存，并重新读取平台列表确认正文和时间。用户反馈本版可用。安装后的整批端到端测试尚未覆盖；平台网页升级或会员限制可能需要适配。目前供本地加载使用，未上架 Chrome Web Store。

## Codex skill

根目录 SKILL.md 提供原生定时操作流程，references/ 包含网页操作经验，scripts/plan.mjs 可独立生成时间表。skill 与 Chrome 扩展可分别使用。

仓库只包含通用代码和说明，不包含账号信息、浏览器凭据或个人发布记录。
