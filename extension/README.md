# 微博 / X 原生定时助手 · v0.1.8

复用当前 Chrome 已登录的账号，把文字帖保存到微博和 X 的原生定时列表。无需 OpenCLI、Codex 或付费 API。保存并核对完成后，帖子由平台发送，电脑无需一直开着。

## 安装和更新

下载仓库，或下载 [v0.1.8 安装包](../downloads/social-native-scheduler-chrome-v0.1.8.zip) 并解压。打开 chrome://extensions，开启开发者模式，加载含 manifest.json 的文件夹；下载仓库时选择 extension/。

更新时覆盖原加载文件夹，在扩展管理页点击刷新，关闭旧助手页后重新打开。

## 使用

一次粘贴全部文案，每条之间连续按两次回车，留一行空白。单次回车保留在同一条文案内。选择北京时间的开始时间、间隔和目标平台，点击“导入全部文案并生成时间表”。两个平台使用相同正文和时间。

打开平台并登录，回助手刷新账号列表，选择已识别的账号，无需手填账号名。微博昵称不可读时显示账号 ID；定时编辑器使用 weibo.com/manage/schedule，首页只用于读取身份。

点击“一次性导入全部到平台”。扩展激活目标网页并依次填写正文、设置时间、点击原生定时保存，无需逐条点击 Schedule 或发送。保持浏览器和助手页开启，直到导入结束。

导入结束后点击“启动检查”，在平台待发布列表中按清单统一检查正文、完整日期和时间，再记录整批已核对。完成状态表示人工核对，不是自动核验服务器结果。

## 中断与重试

只处理尚未导入的条目。遇到账号变化、控件不匹配、超时或结果不明时停止。先检查平台待发布、已发布列表；确认平台没有保存后才能重置，不要直接重复提交。

替换本地计划、重置或卸载扩展不会取消平台帖子，取消需在平台操作。导出记录包含正文和账号信息，请自行保管。

## 支持范围和验证

- 文字帖；不处理图片、视频、长文、验证码或会员购买。
- 时间固定北京时间，X 日期选择器支持英文和部分中文标签。
- 平台会员能力、额度、正文限制及网页变化会影响使用。
- 2026-10-05 已在微博、X 各验证一条完整多行正文的填写、定时保存和服务器列表结果；通过浏览器连接调用同一驱动函数。安装后的整批端到端测试尚未覆盖，详见 [验证记录](VERIFICATION.md)。
- 用户反馈 v0.1.8 可用；未上架 Chrome Web Store。

## 隐私

storage 保存文案、时间表、从网页读取的账号身份和任务状态；scripting 在指定的平台页或框架读取及操作定时编辑器。网站访问限 x.com 和 weibo.com 及微博子域。不读取 Cookie API、密码或令牌，不向发布者发送数据，没有统计追踪或远程代码。保存帖子时，内容通过目标平台网页提交给该平台。

详见 [隐私政策](../PRIVACY.md)。
